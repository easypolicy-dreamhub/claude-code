# Action Plan — design (draft for review)

A new **Action Plan** card in the E3 toolkit. It replaces the "New Associate Action Plan" spreadsheet: same programme, plus target weeks, real progress counts, an approval queue, and one overview of every new associate.

Nothing here is built yet. Everything can change.

---

## 1. In one line
**One template (you edit it) → each new associate gets a plan with a start date → items fall due by target week → the agent ticks or counts → you approve or send back → you see everyone on one screen.**

- **Agents** see only their own plan.
- **You (super admin)** see every plan, approve, and edit the template.
- **Group Managers (team admins)** approve and send back for the people **below them in the team**, nothing else.
- Only **Team members** get a plan, and **you choose who** with an **Assign** button (see section 6). The card itself is switched on per person in **Members & Access**.

---

## 2. The template

Each item has:
- **Section** — Preparation, Knowledge, Kick Start, Practical, Talent Acquisition (sections can be added, renamed, reordered, turned off)
- **Task** and **details**
- **Target week** — 1 to 13
- **Type**
  - **Tick** — done / not done (e.g. Family Visit)
  - **Count** — a number with a target (e.g. Presentation 0/50)
  - **Auto-count** — the number fills itself from the toolkit (section 7)
- **Shortcut** (optional) — an "Open tool" button to a toolkit tool (section 7)

Rows that are really columns are folded into one item: "Prospect list of 100" lists Name, Relationship, Location, Age, Occupation, Category in its details. Course codes (TCF …) sit in one item's details, so they are updated in one place each year.

## 3. Adding, turning off and removing items

### For everyone (template)

| Action | What happens |
|---|---|
| **Add** | Choose section, task, details, week, type. Appears on every plan in progress and on new ones. If its week has already passed for someone, it falls due one week from now (never instantly overdue). |
| **Edit** | Change wording, week or target (e.g. presentations 50 → 40). Everyone updates; progress already made is kept. |
| **Turn off** | Disappears from all plans and stops counting towards % done / Behind. Nothing is lost: turn it back on and it returns with everyone's progress as it was. |
| **Remove** | Asks first. Never started by anyone → deleted. Done or approved by anyone → **archived**: gone from plans, kept in those people's history and Day-90 record. |
| **Reorder / move** | Drag up or down, or move to another section. |
| **Sections** | Add, rename, reorder, turn off a whole section. |

### For one person (their page)

| Action | Use |
|---|---|
| **Not needed for this person** | Already done elsewhere (transfer, experienced). Skipped for them only, does not count against them, optional note. Undo any time. |
| **Extra item for this person** | Something only for them (e.g. "Redo the questioning role-play with buddy"). |

### Safety
- Turning off or removing never deletes anyone's approved work.
- Every change is in the audit log (what, when, by whom).
- Only you edit the template or skip items.

## 4. Status of each item (replaces the colours)

| Status | Was | Next |
|---|---|---|
| **Not yet assigned** | blank | Assigns itself when its week arrives, or you assign it early |
| **To do** | — | The agent works on it |
| **Waiting for you** | — | Agent ticked it / reached the count; it is in your approval queue |
| **Done** | green | You approved it (date and approver saved) |
| **Follow up** | yellow | You sent it back with a note; the agent sees the note |

Count items show progress all the time (e.g. 18/50) and go to **Waiting for you** when the target is reached.

---

## 5. On track or behind — weeks are a guide, not a rule
- **Agents see gentle wording:** "Suggested by week 5", never "overdue". Only you (and approvers) see the **Behind** / **A little behind** labels.
- **Plan length per person.** Default 90 days. For someone who needs longer (or shorter) you set e.g. 120 or 150 days, and every target week stretches in proportion.
- **One-off changes on a person's page:** move a single item to a different week for them, skip an item, add an extra item, or change a count target for them only (e.g. presentations 40 instead of 50 for a part-timer).
- **A grace margin** — someone shows as behind only when well under the expected pace.
- **Week** is counted from each agent's **start date** ("Week 5 of 13").
- **Tick items** are overdue once their target week has passed.
- **Count items** are compared with the expected pace (presentations over weeks 3–12: by week 7, about 25 expected). Under about 80% of the pace → **Behind**.
- Each agent gets one label: **On track**, **A little behind**, **Behind**.

## 6. Screens

- **A. My Action Plan (agent)** — "Week 5 of 13", overall progress, label; items by section with **Tick** or **+ / −** (or Auto); your notes; **This week** at the top; shortcut buttons to tools.
- **Assign plan (you)** — a button on the Overview: choose a Team member, set their start date, press **Assign**. That creates their plan from the current template. Anyone not assigned has no plan.
- **B. Overview (you, and Group Managers for their own team)** — one row per associate: name, DISC letter, your private number, week, % done, label, **waiting for you**, **follow-ups**. Sort by most behind / most waiting.
- **C. Approvals (you)** — everything ticked by everyone: **Approve** (one tap) or **Send back** with a note.
- **D. Person page (you)** — their full plan plus: start date, assign early, approve / send back, notes, **Not needed for this person**, **Extra item**, and a **WhatsApp nudge** with a ready message.
- **E. Template editor (you)** — add, edit, turn off, remove, reorder items and sections.

## 8. DISC and your number
- **DISC** — taken from Career Code when the agent did the test as a candidate; otherwise you choose it. A short coaching hint shows on their page (e.g. "I: motivate with recognition and team activities").
- **Your number** — a private field only you see. You type the number; no full birth date is stored.

## 10. Build steps
1. **Core** — template with add / edit / turn off / remove, per-person skip and extra items, plans with start dates, tick and count, approvals, overview, target weeks and labels. Enough to retire the spreadsheet.
2. **Toolkit links** — auto-counts from the Client Portal and Career Code, shortcut buttons, DISC from Career Code.
3. **Extras** — WhatsApp nudges, printable Day-90 review, buddy view.

Moving the current associates across: after step 1, set up their plans and mark what is already done (or import from CSV exports of the sheets).

## 11. Decisions so far (your answers)
1. **Target weeks** — a shared guide that bends per person (section 5); pacing in section 2 still to be confirmed.
2. **The ➕ items** — kept: product knowledge, objection handling, policy delivery, policy summary sheet, ePolicy folder (5), plus the Day-90 review. Any can be turned off later.
3. **Note types** — **Open** counts as a market survey; **Recruit** counts for Career Introduction.
4. **Approvals** — you **and team admins** (Group Managers you have switched on as team admins on the Team page), for their own team only. Today nobody is a Group Manager or team admin, so you are the only approver; it widens automatically when you promote someone and switch the flag on.
5. **Counts** — counted from the Client Portal wherever it can be; the rest are counts the agent enters and an approver confirms. The **point system** is not needed: it stays a plain tick item.
6. **Who gets a plan** — Team members only, by the **Assign** button.
